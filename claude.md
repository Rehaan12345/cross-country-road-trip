Cross country trip tech

Goal: make a mobile-optimized website that documents daily mileage and tracks my route across country.
- Sträva for driving

Basic functionality:
- It tracks my location and follows my route
- I can start and stop location tracking.
    - When I start, it begins tracking.
    - When I end it shows the distance, the route traveled, the time it took, etc.
- Everyday it adds to the map that shows my route across the country.

Technical outline:
- This will be a website, pushed to production for only one user (me)
- The UI has to be optimized for mobile view. It will rarely, if ever, be shown on a laptop screen.
- Use existing, well documented, and pre built live tracking APIs instead of building your own
- Use an open source mapping library for the map features
- Reference the my-agents.md file to use the appopriate agents to carry out the task.
- Use a database that will support this functionality.
- Prioritize building correctly and concisely, and optimimally, rather than just building fast.
- Potential future plan: build in offline functionality (not yet).
